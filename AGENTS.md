# Workspace Guidelines & Rules

## Strict Version Control Rules (PERMANENT)

1. **NO COMMIT WITHOUT PERMISSION**:
   - NEVER execute `git commit` unless the user explicitly instructs or grants permission in that specific turn (e.g. "commit it", "commit now").

2. **NO PUSH WITHOUT PERMISSION**:
   - NEVER execute `git push` unless the user explicitly instructs or grants permission in that specific turn (e.g. "push now", "push it to github").

3. **LOCAL VERIFICATION FIRST**:
   - All code edits, features, and fixes must be tested and verified locally first.
   - Summarize the changes and wait for the user's explicit go-ahead before staging, committing, or pushing.
